01 init

Start from a blank repo, on purpose.

Every build here starts the same way: no framework assumed, no boilerplate kept out of habit. Just the smallest set of files that can run, so every later decision has a reason.

  • Plain HTML / CSS / JS — no build step required
  • One design-token file, referenced everywhere
  • Structure decided before styling begins

// three layers, three speeds — that's the whole trick

02 build

Layout first, effects second.

The scroll effects on this page — the progress rail on the left, the reveal on each section, the drifting layers above — are all added after the structure already worked without them. Motion should support reading, not replace it.

  • IntersectionObserver for section reveals
  • Scroll position mapped to a fill height for the rail
  • Reduced-motion preference respected throughout

03 ship

Small enough to hand off as a zip.

No build tooling, no dependencies to install, nothing to compile. Unzip it, open index.html, and it runs — or drop the folder onto any static host.

  • 3 pages: home, work, contact
  • Fonts loaded from Google Fonts, everything else local
  • Works fully offline aside from the font request
